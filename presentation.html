Problem Statement

Why Do We Need AeroDrop?

Traditional cloud and email file sharing methods have critical bottlenecks:

🚫 File Size Limitations

Email attachments are capped at 25MB, and free cloud lockers enforce strict storage tiers and throttle speeds.

⏳ High Bandwidth Waste

Files upload to an external cloud server and then re-download to the recipient, consuming double bandwidth.

🔒 Data Privacy Vulnerabilities

Uploading sensitive documents, assignments, and media to third-party databases risks breaches and surveillance.

Architecture Concept

AeroDrop Solution & Principles

True browser-to-browser data streaming without cloud intermediaries.

⚡ Peer-to-Peer Data Channels

Leverages native WebRTC data channels. Data travels directly across your local Wi-Fi router or peer network interface at maximum hardware line-rate speed.

🌐 Zero Software Installation

Runs natively inside standard browsers (Chrome, Edge, Safari, Firefox). No executables to download, no user account registrations, and no tracking cookies.

Technical Implementation

Frontend Technical Stack

Engineered strictly adhering to modern web development standards.

  • Semantic tags: <header>, <nav>, <section>, <footer>

⚡ Vanilla JavaScript

Security & UX Highlights

Hardened Security & Interactive UI

Built with defense-in-depth and authentic user interaction.

🛡️ Malware & Executable Blocker

Inspects file signatures. Dangerous executable extensions (.exe, .bat, .sh) are intercepted and rejected by the client security guard.

📡 Interactive Peer Selection

Radar discovers live local nodes. Users can click any peer (e.g. Mukul's Mac, Bhawna's iPhone) to route direct point-to-point packets.

📊 Real-Time Streaming Progress

Visual 64KB chunk streaming animation with dynamic MB/s throughput, ETA countdown, and DTLS completion handshake.

📱 Responsive Navigation Drawer

Full mobile accessibility via animated hamburger drawer, touch swipe support, and Content Security Policy headers.
