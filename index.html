Built-in Defense

Enterprise-Grade Security Architecture

Engineered with zero-trust principles so your files never touch third-party servers.

🛡️

Content Security Policy

Strict CSP rules block unauthorized external scripts, framing attacks, and cross-site scripting (XSS).

🔐

Direct DTLS/SRTP Encryption

Every chunk sent over WebRTC data channels is encrypted in transit using standard cryptographic handshakes.

🚫

Malicious Payload Blocker

Dangerous executable binaries (.exe, .bat, .cmd, .sh, .vbs) are inspected and blocked before streaming.

🧹

Zero DOM XSS Policy

All dynamic content is rendered through strict text node bindings and escaped entities to prevent code injection.

High Performance

Why AeroDrop Outperforms the Cloud

No waiting for cloud servers to re-encode, throttle, or inspect your private files.

⚡

Line-Rate Speed

Data packets travel directly over your local Wi-Fi router or peer network interface at full local bandwidth.

📦

Uncapped File Sizes

No arbitrary 25MB attachment limits. Stream massive ISO files, raw camera dumps, and archives directly.

📱

Cross-Platform Web Mesh

Works seamlessly across macOS, Windows, Linux, iOS, and Android without installing any native client apps.

🧠

Backpressure Streaming

Smart buffer flow-control prevents browser memory overflow by slicing large files into sequential 64KB chunks.

Workflow

How It Works in 3 Steps

Simple, frictionless data sharing with zero registration or logins.

01

Pick or Drop Files

Drop your file into the secure dropzone. The client checks the file signature, MIME type, and size in real time.

02

Pair Peer Node

The radar discovers active peers on the same mesh room. Tap any peer or broadcast to everyone at once.

03

Direct Stream

Files stream directly between device buffers via encrypted WebRTC data channels with live progress tracking.
